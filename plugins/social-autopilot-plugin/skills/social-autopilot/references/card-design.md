# 新闻卡片设计规范

## 尺寸

- **画布**: 1080 x 1080 px（Instagram 正方形帖子标准尺寸）
- **内边距**: 60px
- **安全区域**: 距边缘至少 60px 内的内容

## 布局结构

```
┌────────────────────────────────────────┐
│  📰 NOTÍCIA               ● ● ● ●    │
│                            ● ● ● ●    │
│                            ● ● ● ●    │
│                                        │
│                                        │
│                                        │
│                                        │
│  ┌─ CATEGORY ─┐                       │
│                                        │
│  新闻标题文字                          │
│  （最多3行，超出截断）                  │
│                                        │
│  ────                                  │
│  [G] GEEK STORE                       │
└────────────────────────────────────────┘
```

## 字体

- **标题**: Montserrat Black (900), 56px, 行高 1.15
- **分类标签**: Montserrat Bold (700), 20px, 大写, 2px letter-spacing
- **品牌名**: Montserrat Bold (700), 20px

## 视觉元素

1. **渐变背景**: 品牌色到深色变体（混入60%黑色），135度角
2. **装饰性圆点**: 右上角 4x3 网格，半透明白色
3. **新闻标签**: 左上角，📰 NOTÍCIA，半透明背景
4. **分类徽章**: 圆角胶囊形，半透明背景+模糊
5. **分隔线**: 80px宽，4px高，半透明白色
6. **品牌区域**: logo方块 + 品牌名，底部左对齐

## 模板变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `{{TITLE}}` | 新闻标题 | "Marvel anuncia novo filme dos Vingadores" |
| `{{CATEGORY}}` | 分类显示名 | "MARVEL" |
| `{{BRAND_COLOR}}` | 品牌主色 | "#E23636" |

## 标题截断规则

- 最大行数: 3行
- 最大高度: 390px (overflow: hidden)
- 理想长度: 60~80字符（葡萄牙语）
- 过长时 CSS 自动截断，无需显式省略号
