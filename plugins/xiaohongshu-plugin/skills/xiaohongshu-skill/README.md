## 内容创作指南

### 标题创作（≤20字）

**好的标题示例**：
- ✅ "3个技巧让你的照片更高级 📸"
- ✅ "终于找到了！平价好用的护肤品 💕"
- ✅ "新手必看｜5分钟学会化妆 ✨"

**避免**：
- ❌ "分享一下我的日常"（太平淡）
- ❌ "今天天气真好"（无价值点）

### 内容结构（≤500字）

```
【开头】吸引注意（1-2行）
    ↓
【主体】核心内容（分点呈现）
    ↓
【结尾】互动引导（话题标签）
```

### 质量检查清单

```
发布前检查：
- [ ] 标题是否吸引人？（≤20字）
- [ ] 开头是否抓住注意力？
- [ ] 内容是否有实用价值？
- [ ] 排版是否清晰易读？
- [ ] emoji使用是否恰当？
- [ ] 是否有互动引导？
- [ ] 话题标签是否精准？（3-6个）
- [ ] 总字数是否≤500字？
```

## 平台规范

**内容要求**：
- 标题：≤20字符
- 正文：≤500字符
- 格式：支持emoji、换行、话题标签

**禁忌事项**：
- ❌ 硬广、微商内容
- ❌ 虚假宣传
- ❌ 抄袭他人内容
- ❌ 标题党
- ❌ 排版混乱

**发布时间建议**：
- 早上 7:00-9:00（通勤时间）
- 中午 12:00-14:00（午休时间）
- 晚上 18:00-22:00（黄金时段）
